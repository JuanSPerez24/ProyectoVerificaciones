# Proyecto Verificaciones

Aplicación web para el registro y consulta de solicitudes. Incluye gestión de usuarios, roles y búsquedas filtradas.
Está desarrollada con **Node.js (Express)** en el backend y **HTML, CSS y JavaScript** en el frontend.

---

## Características

* Login y control de acceso
* Registro y consulta de solicitudes
* Búsquedas por texto y estado
* Consulta detallada por ficha
* Gestión de usuarios
* API REST
* Base de datos relacional

---

## Tecnologías

**Backend**

* Node.js
* Express
* SQL

**Frontend**

* HTML
* CSS
* JavaScript

---

## Instalación

1. Clonar el repositorio

   ```
   git clone https://github.com/tu-usuario/ProyectoVerificaciones.git
   ```

2. Instalar dependencias

   ```
   cd ProyectoVerificaciones/Backend
   npm install
   ```

3. Configurar la base de datos ejecutando los scripts SQL que están en:

   ```
   Backend/BD/
   ```

4. Iniciar el servidor

   ```
   node server.js
   ```

---

## Estructura del proyecto
