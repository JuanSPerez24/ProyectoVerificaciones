# 📝 Proyecto Verificaciones

Aplicación web para la **gestión, registro y consulta de solicitudes**, desarrollada con **Node.js (Express)** en el backend y **HTML/CSS/JavaScript** en el frontend.
El sistema permite administrar usuarios, roles y solicitudes, así como realizar búsquedas filtradas y visualizar información detallada.

---

## 🚀 Características principales

* Login y control de acceso por roles
* Registro y consulta de solicitudes
* Consulta detallada por ficha
* Búsqueda por texto y estado
* CRUD básico de usuarios
* Listas desplegables dinámicas
* API REST modular
* Base de datos relacional

---

## 🛠️ Tecnologías utilizadas

**Backend**

* Node.js
* Express
* SQL Server / MySQL (dependiendo configuración)

**Frontend**

* HTML
* CSS
* JavaScript

## ⚙️ Instalación

1. Clonar repositorio:

```bash
git clone https://github.com/tu-usuario/ProyectoVerificaciones.git
```

2. Instalar dependencias:

```bash
cd ProyectoVerificaciones/Backend
npm install
```

3. Configurar base de datos ejecutando los scripts:

```
Backend/BD/CreacionDeBDyTablas.sql
```

4. Ejecutar servidor:

```bash
node server.js
```

El backend se ejecutará por defecto en:

```
http://localhost:3000
```
